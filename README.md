## 📱 วิธีเปิดใช้งาน GitHub Pages (Step-by-Step Guide)

หากต้องการเปิดให้เว็บไซต์ออนไลน์ผ่าน GitHub Pages สามารถตั้งค่าได้ง่ายๆ ใน 4 ขั้นตอน:

1. **ไปที่เมนูการตั้งค่า:** คลิกแท็บ **`Settings`** (ขวาสุดของเมนูด้านบนในหน้านี้)
2. **เลือกเมนู Pages:** ที่แถบเมนูด้านซ้าย ในหมวด *Code and automation* ให้คลิกเลือก **`Pages`**
3. **กำหนด Branch ที่จะเผยแพร่:**
   * ตรงหัวข้อ **Build and deployment** > **Source** ให้เลือกเป็น `Deploy from a branch`
   * ในส่วนของ **Branch** ให้เปลี่ยนจาก `None` เป็น **`main`** และเลือกโฟลเดอร์เป็น **`/(root)`**
   * กดปุ่ม **`Save`** สีน้ำเงิน
4. **เข้าใช้งานได้ทันที:** รอระบบประมวลผลประมาณ 1–2 นาที หน้าเว็บจะแสดงกรอบสีเขียวแจ้งว่า:  
   *"Your site is live at https://chaisupap.github.io/english/"*

## 🌟 แดชบอร์ดและฟังก์ชันการใช้งานภายในระบบ

### 1. 🎯 120 Phrasal Verbs Interactive Dashboard (`index.html`)
คลังรวม **120 คำกริยาววลี (Phrasal Verbs)** ที่พบบ่อยที่สุดในการสื่อสารและข้อสอบมาตรฐาน (IELTS, TOEFL, TOEIC, KEPT):
* 🔊 **ระบบเสียงสตูดิโอ 4 จุดต่อการ์ด:**
  1. เสียงกริยาววลี (Phrasal Verb)
  2. เสียงคำนิยามสั้นภาษาอังกฤษ (English Meaning)
  3. เสียงตัวอย่างประโยคในชีวิตประจำวัน (Example Sentence 1)
  4. เสียงตัวอย่างประโยคสถานการณ์เพิ่มเติม (Example Sentence 2)
* 🎨 **ระบบเน้นคำอัจฉริยะ (Smart Color Highlighting):** แยกสีส่วนที่เป็น Base Verb และ Preposition/Particle ให้สังเกตโครงสร้างได้ทันที
* 🎚️ **ระบบปรับความเร็วเสียงแบบเรียลไทม์ (Live Speed Pitch):** เลือกปรับได้ 5 ระดับ `0.75x`, `0.85x`, `1.0x (ปกติ)`, `1.15x`, `1.25x` เปลี่ยนความเร็วได้ทันทีขณะกำลังฟัง
* 📑 **3 โหมดมุมมองการเรียนรู้:**
  * **โหมดการ์ด (Cards View):** จัดวางสวยงาม อ่านง่าย สบายตา
  * **โหมดตาราง (Table View):** เปรียบเทียบข้อมูลแบบย่อ เหมาะสำหรับการทบทวนอย่างรวดเร็ว
  * **โหมดท่องจำแฟลชการ์ด (3D Interactive Flashcards):** พลิกการ์ดหน้า-หลังเพื่อทดสอบความจำ พร้อมระบบสุ่มคำศัพท์ (Shuffle)
* 🔍 **ระบบค้นหาแบบ Instant Search:** ค้นหาได้ทั้งภาษาอังกฤษและภาษาไทย พร้อมตัวกรองตามตัวอักษร A–Z และคำบุพบท (Particles) เช่น `up`, `down`, `off`, `in`, `out`

### 2. 🎓 300 Basic to Academic Words Dashboard (`words/index.html`)
เครื่องมือยกระดับคลังคำศัพท์ **300 คู่คำ จากคำศัพท์พื้นฐานทั่วไป (Basic Words) สู่คำศัพท์เชิงวิชาการระดับสูง (Academic Words)**:
* 🔄 **การจับคู่คำศัพท์แบบ Direct Comparison:** แสดงเปรียบเทียบคำพื้นฐานกับคำวิชาการเคียงข้างกันอย่างชัดเจน
* 🎙️ **เสียงพากย์สตูดิโอคุณภาพสูง (Jenny Neural Studio HD):** บันทึกเสียงแยกทุกคำศัพท์และทุกประโยคตัวอย่าง
* 📖 **สัทศาสตร์สากล (IPA Phonetics & Stressing):** มีสัญลักษณ์สัทศาสตร์พร้อมเน้นตำแหน่งการลงน้ำหนักพยางค์ (Stress) อย่างถูกต้อง
* 📝 **ประโยคตัวอย่างคู่ขนาน (Dual Comparative Contexts):**
  * **ประโยคที่ 1 (Casual/Daily):** บริบทชีวิตประจำวันและการสื่อสารทั่วไป
  * **ประโยคที่ 2 (Formal/Academic):** บริบทงานวิจัย เอกสารวิชาการ และการเขียนระดับทางการ
* ⭐ **ระบบบุ๊กมาร์ก (Personal Favorites):** บันทึกคำศัพท์ที่ต้องการฝึกฝนเป็นพิเศษ จัดเก็บลงใน LocalStorage ของอุปกรณ์โดยอัตโนมัติ

├── .gitattributes         # การตั้งค่า Git Line Endings & LFS

## 💻 เทคโนโลยีที่ใช้พัฒนา (Tech Stack)

* **UI Framework:** HTML5, Tailwind CSS (Modern Slate & Royal Indigo Palette)
* **Typography:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) (สากลคมชัด) & [Prompt](https://fonts.google.com/specimen/Prompt) (ภาษาไทยอ่านสบายตา)
* **Audio Engine:** HTML5 Audio API พร้อม Fallback Web Speech API อัตโนมัติ รองรับการเล่นเสียงแบบออฟไลน์และออนไลน์
* **Hosting Platform:** GitHub Pages (Zero-configuration Serverless Web Hosting)
