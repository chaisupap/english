หลักเกณฑ์ไวยากรณ์ประโยคเงื่อนไข (Conditional Sentences)

สรุปโครงสร้าง 5 รูปแบบ วิธีการใช้ และข้อแตกต่าง

0. Zero Conditional (ความจริงทั่วไป / กฎธรรมชาติ)

โครงสร้าง: If + Present Simple (V.1), Present Simple (V.1)

ใช้เมื่อผลลัพธ์เป็นความจริงทางวิทยาศาสตร์ กฎธรรมชาติ หรือความจริงเสมอ เช่น If you heat ice, it melts. (ถ้าต้มน้ำแข็ง น้ำแข็งจะละลาย)

1. First Conditional (เป็นไปได้จริงในปัจจุบันหรืออนาคต)

โครงสร้าง: If + Present Simple (V.1), Future Simple (will + V.1)

ใช้กับเหตุการณ์ที่มีโอกาสเกิดขึ้นจริงในชีวิตประจำวัน เช่น If it rains, I will stay at home. (ถ้าฝนตก ฉันจะอยู่บ้าน)

2. Second Conditional (เหตุการณ์สมมติในปัจจุบันหรืออนาคต)

โครงสร้าง: If + Past Simple (V.2 / were), would + V.1

ใช้กับเหตุการณ์สมมติที่ตรงข้ามกับความจริงในปัจจุบัน หรือเป็นไปได้ยากมากในอนาคต (ใช้ were กับประธานทุกตัว) เช่น If I were you, I would accept the offer. (ถ้าฉันเป็นคุณ ฉันคงตอบรับข้อเสนอไปแล้ว)

3. Third Conditional (เหตุการณ์สมมติในอดีต / เสียดาย)

โครงสร้าง: If + Past Perfect (had + V.3), would have + V.3

ใช้กับเหตุการณ์สมมติตรงข้ามกับความจริงในอดีต ซึ่งผ่านพ้นไปแล้วและไม่สามารถแก้ไขได้ มักใช้แสดงความเสียดาย เช่น If I had studied hard, I would have passed the exam. (ถ้าตอนนั้นตั้งใจเรียน ฉันคงสอบผ่านไปแล้ว)

4. Mixed Conditional (ประโยคเงื่อนไขแบบผสมข้ามกาลเวลา)

แบบ A (ข้อ 161-180): If + Past Perfect, would + V.1 now

สมมติอดีตที่ส่งผลกระทบต่อเนื่องถึงสภาพในปัจจุบัน เช่น If I had studied medicine, I would be a doctor now. (ถ้าตอนนั้นเรียนหมอ ตอนนี้ก็คงได้เป็นหมอแล้ว)

แบบ B (ข้อ 181-200): If + Past Simple (were), would have + V.3

สมมติสภาพปัจจุบันหรืออุปนิสัยทั่วไป ที่ส่งผลต่อเหตุการณ์ในอดีต เช่น If I were taller, I would have joined the basketball team. (ถ้าฉันเป็นคนตัวสูง ตอนนั้นคงเข้าทีมบาสไปแล้ว)
